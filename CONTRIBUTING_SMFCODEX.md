# Contributing to SMFCodex

Thank you for your interest in contributing to SMFCodex!
This project blends esoteric mathematics with practical engineering, and thoughtful contributions are welcome.

## Ways to contribute
- Report bugs or unexpected behavior via GitHub Issues.
- Suggest new features, codecs, or transformations.
- Improve documentation, examples, or tests.

## Contribution guidelines
- Open an Issue before starting major work to align on scope.
- Fork the repo and create a feature branch for your changes.
- Write clear commit messages and include tests or examples when relevant.
- Submit a Pull Request with a concise description of your changes and any breaking impact.

## Code style and tests
- Follow existing code style and structure in the project.
- Add or update tests where appropriate.

## Code of conduct
- Be respectful, constructive, and concise in all interactions.
- Discriminatory or hostile behavior will not be tolerated.
